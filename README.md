# Personal Finance Advisor Bot

An AI-powered personal finance planning assistant. Log income and expenses,
get an automatically generated budget plan, track saving goals, and view
monthly financial reports — with AI-driven insights when a Gemini API key
is configured (falls back to a built-in rule-based 50/30/20 engine
otherwise, so it works fully offline out of the box).

## Features
- User registration/login (salaried professional, student, freelancer, household roles)
- Log monthly income (with recurring-income support)
- Log daily/weekly expenses across 10 categories
- Auto-generated monthly budget plan (needs/wants/savings, per-category limits)
- AI-driven spending insights (Gemini, with rule-based fallback)
- Saving goals with progress tracking and contributions
- Monthly financial report with category breakdown, selectable by month
- Dashboard with a live spending-by-category chart

## Tech Stack
- Backend: Flask, Flask-SQLAlchemy, Flask-Login
- Database: SQLite (swap `DATABASE_URL` for Postgres/MySQL in production)
- AI: Google Gemini (`google-generativeai`), with a deterministic fallback
- Frontend: Jinja2 templates, Bootstrap 5, Chart.js

## Setup

```bash
cd finance_advisor_bot
python3 -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env
# edit .env: set SECRET_KEY, optionally GEMINI_API_KEY

python app.py
```

Visit http://localhost:5000, register an account, and start logging income
and expenses. The database file `finance_advisor.db` is created
automatically on first run.

## Deploying to Vercel

The repository is configured for Vercel's Python runtime. Import the GitHub
repository into Vercel with the repository root as the project root; Vercel
detects the Flask `app` in `app.py`, and serves the stylesheet from `public/`.

Before deploying, add these environment variables in the Vercel project
settings for every environment you use:

- `SECRET_KEY`: a long, random value. Generate one with
  `python -c "import secrets; print(secrets.token_urlsafe(48))"`.
- `DATABASE_URL`: a persistent PostgreSQL connection URL in the form
  `postgresql+psycopg://user:password@host:5432/database`. Vercel's filesystem
  is ephemeral, so the local SQLite database is intentionally rejected in
  production.
- `GEMINI_API_KEY` (optional): enables Gemini-powered insights.

After setting the variables, deploy from Vercel or push a commit to the
connected GitHub repository. Do not commit `.env` files, database files, or
the local virtual environment.

## Enabling AI-powered insights
Get a free Gemini API key from https://aistudio.google.com/app/apikey and
set `GEMINI_API_KEY` in `.env`. Without it, the app still works — insights
and the budget narrative are generated by a rule-based engine instead.
